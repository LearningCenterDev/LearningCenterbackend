# Learning Center Backend

A robust, modular Node.js API server built with Express and TypeScript, designed to power a comprehensive eLearning platform.

## 🚀 Main Idea & Concepts

The backend serves as the core engine for the Learning Center, handling authentication, data persistence, business logic, and complex workflows like course enrollment, financial billing, and teacher-student interactions.

### Key Architectural Concepts

- **Modular Routing**: Routes are organized by feature (e.g., `auth`, `courses`, `enrollments`, `finance`) for high maintainability.
- **Abstracted Storage**: A storage layer (`IStorage` interface) abstracts the database operations, allowing for easier testing and flexible implementations (e.g., in-memory for testing, PostgreSQL for production).
- **Type-Safe Data Flow**: Extensive use of TypeScript and Zod schemas for end-to-end type safety from the database to the API responses.
- **JWT Authentication**: Secure, stateless authentication using JSON Web Tokens with refresh token rotation.

## 📂 Folder Structure

```text
LearningCenterbackend/
├── server/                 # Main server logic

│   ├── routes/             # Modular API route definitions
│   │   ├── index.ts        # Modular route registration
│   │   ├── auth.ts         # Login, logout, refresh tokens

│   │   ├── courses.ts      # Course & curriculum management
│   │   ├── finance.ts      # Invoices, payments, fee plans
│   │   └── ...             # Other feature-specific routes
│   ├── db.ts               # Database connection (Drizzle)
│   ├── db-storage.ts       # Concrete IStorage implementation using Drizzle
│   ├── storage.ts          # IStorage interface & in-memory backup
│   └── index.ts            # Application entry point
├── shared/                 # Shared schemas and types with Frontend
│   └── schema.ts           # Drizzle schema & Zod definitions
├── migrations/             # SQL migration files generated by Drizzle
├── .env                    # Environment variables (DB_URL, secrets)
├── package.json            # Dependencies and scripts
└── tsconfig.json           # TypeScript configuration
```

- **Runtime**: Node.js
- **Framework**: Express.js
- **Language**: TypeScript

## 🚦 Getting Started

### Prerequisites
- Node.js (v18+)
- PostgreSQL instance

### Installation

1. Install dependencies:
   ```bash
   npm install
   ```

2. Configure Environment:
   Create a `.env` file in the root based on existing variables:
   ```env
   DATABASE_URL=postgresql://user:password@localhost:5432/learning_center
   SESSION_SECRET=your_secret_key
   PORT=5001
   ```

3. Setup Database:
   ```bash
   npm run db:push
   ```

4. Start Development Server:
   ```bash
   npm run dev
   ```

---

## 🔧 Scripts

- `npm run dev`: Starts the server with `tsx` for development.
- `npm run build`: Compiles TypeScript to JavaScript in `dist/`.
- `npm run start`: Runs the built production server.
- `npm run db:push`: Pushes schema changes directly to the database.
- `npm run db:generate`: Generates migration files.
